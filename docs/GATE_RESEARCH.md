# Шлюз, расшифровка TLS и частый опрос — разбор (2026-11-19)

Три исследования (агенты, только поиск и чтение кода; на живой системе ничего не проверялось).
Вопрос пользователя: провайдер VPN сам выводит через другую страну (локально ничего не меняется) —
как ловить быстрее 1–3 с и «точно ли частый опрос то же самое, что шлюз».

## Факты
* Открытое TCP-соединение не «переезжает» на другой выход: либо остаётся на старом, либо рвётся.
  Через новый выход идут **новые** соединения; первым же запросом в них уходит токен/куки.
* pf пропускает пакеты открытых соединений без проверки правил — фильтр «по новым» старые не трогает.
* Новые соединения: Electron — единицы в минуту (простой до 300 с), Node undici — простой 4 с
  (до 600 с по подсказке сервера), Bun — 5 мин; поток SSE держит соединение минутами.
* Проверка страны и соединение приложения — разные потоки. Провайдер (или правила xray по домену)
  может пустить их через разные выходы. Это не закрывает ни опрос, ни шлюз без расшифровки.
* Хосты Anthropic отвечают на `/cdn-cgi/trace` (проверено через туннель 18.11: тот же IP и DE).
* Network Extension (как LuLu/Little Snitch, `NEFilterDataProvider.pause`) — только с платным
  аккаунтом Apple ($99/год). Без него — pf `route-to lo0` + `rdr` (как прозрачный режим mitmproxy);
  с utun Happ не проверено, для IKEv2 требовался `reply-to lo0`.
* Расшифровка TLS (свой корневой сертификат): Claude Code официально принимает сертификат из
  системного хранилища; риски — утечка ключа (перехват всего TLS на Маке), ошибки проверки
  сертификата (NDSS 2017, US-CERT TA17-075A), поломка SSE/WebSocket, другой отпечаток TLS (JA3/JA4)
  с неизвестным риском для аккаунта. Готового аналога «проверка выхода на том же соединении» нет.
* pf сам записи таблиц не удаляет: `pfctl -T expire N` надо кому-то запускать.

## Окно, когда новое соединение может уйти не из той страны (оценка, не замер)
| схема | окно |
|---|---|
| сейчас (1.0.8), опрос 1 раз/с | ~1,1–1,5 с |
| опрос 2 раза/с | ~0,35–0,8 с |
| шлюз без расшифровки (проверка перед соединением) | ~0,05–0,3 с |
| шлюз с расшифровкой | ~0, но см. риски |

## Вывод
Шлюз с расшифровкой — нет. Полный шлюз — дорого, выигрыш 0,8 → 0,3 с, и потоки всё равно разные.
Дешёвая связка: опрос 2 раза/с + «пропуск» в pf для новых соединений (таблица, которую демон
обновляет после каждого хорошего ответа, и отдельный процесс-рубильник, чистящий её, если демон
завис) + белый список стран + редкая проверка на хостах Anthropic (тот же путь по домену).
