# Установка VPN Guard

Нужно: macOS 12 или новее, Apple Silicon или Intel, пароль администратора.

## С DMG (на другом Маке)

1. Открыть `VPN-Guard.dmg`.
2. Открыть Терминал и выполнить (путь — к смонтированному диску):

   ```bash
   sudo "/Volumes/VPN Guard/install.sh"
   ```

   Установщик ставит демон, настройки и копирует `VPN Guard.app` в «Программы».
3. Открыть **VPN Guard** из «Программ» → отметить приложения → «Сохранить»
   (спросит пароль).
4. Проверить: `sudo vpn-guard status` — должно быть `VPN: ПОДНЯТ` при включённом VPN.

Если macOS пишет «не удаётся проверить разработчика» — приложение не подписано
сертификатом Apple. Правый клик по нему → «Открыть» → «Открыть». Установщик и так
снимает эту пометку, так что обычно не нужно.

## Из исходников (этот репозиторий)

```bash
./app/build.sh          # собрать приложение (нужны Xcode Command Line Tools)
sudo ./install.sh       # поставить всё
./make-dmg.sh           # при желании — собрать DMG для другого Мака
```

## После установки — рекомендуется

* **Запрет запуска для защищённых приложений** (Claude, Chrome и т.п.): macOS не
  даёт менять их файлы. Без этого приложение откроется, но замёрзнет через 2 с.
  Чтобы запуск тоже запрещался: Системные настройки → Конфиденциальность и
  безопасность → **Управление приложениями** → добавить `/bin/zsh`.
* **Автозапуск окна**: Системные настройки → Основные → Объекты входа → добавить
  VPN Guard. (Сам демон стартует при загрузке и без этого.)
* **VPN в режиме прокси** — поменять правила проверки, см. README.

## Удаление

```bash
sudo vpn-guard uninstall
sudo rm -rf "/Applications/VPN Guard.app" /usr/local/bin/vpn-guard /usr/local/etc/vpn-guard.conf /usr/local/etc/vpn-guard.apps
```
