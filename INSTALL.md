# Установка Vafa

Нужно: macOS 12 или новее, Apple Silicon или Intel, пароль администратора.

## С DMG (на другом Маке)

1. Открыть `Vafa.dmg`.
2. Открыть Терминал и выполнить (путь — к смонтированному диску):

   ```bash
   sudo "/Volumes/Vafa/install.sh"
   ```

   Установщик ставит демон, настройки и копирует `Vafa.app` в «Программы».
3. Открыть **Vafa** из «Программ» → отметить приложения → «Сохранить»
   (спросит пароль).
4. Проверить: `sudo vpn-guard status` — должно быть `VPN: ПОДНЯТ` при включённом VPN.

Если macOS пишет «не удаётся проверить разработчика» — приложение не подписано
сертификатом Apple. Правый клик по нему → «Открыть» → «Открыть». Установщик и так
снимает эту пометку, так что обычно не нужно.

## Из исходников (этот репозиторий)

```bash
./app/build.sh          # собрать приложение (нужны Xcode Command Line Tools)
sudo ./install.sh       # поставить всё
./make-dmg.sh           # при желании — собрать DMG для другого Мака
```

## После установки — рекомендуется

* **Запрет запуска для защищённых приложений** (Claude, Chrome и т.п.): macOS не
  даёт менять их файлы. Без этого приложение откроется, но замёрзнет через 2 с.
  Чтобы запуск тоже запрещался: Системные настройки → Конфиденциальность и
  безопасность → **Управление приложениями** → добавить `/bin/zsh`.
* **Автозапуск окна**: Системные настройки → Основные → Объекты входа → добавить
  Vafa. (Сам демон стартует при загрузке и без этого.)
* **VPN в режиме прокси** — поменять правила проверки, см. README.

## Windows

1. Скачать репозиторий (Code → Download ZIP) и распаковать.
2. В папке `windows` дважды щёлкнуть **install.cmd** → разрешить в окне UAC.
   Ставится служба (задача Планировщика от SYSTEM, стартует при загрузке),
   трей-приложение и ярлык «Vafa» в меню «Пуск».
3. Щит в трее → двойной щелчок → отметить приложения → «Сохранить».
   В меню щита: «Охрана включена», «Запускать при входе в Windows», журнал.

Удаление: PowerShell **от администратора**, в распакованной папке `windows`:

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

Что проверено (Windows 11 ARM в Parallels, 2026-09-28): заморозка процессов,
запрет запуска (`Access is denied`), разморозка при появлении VPN, статус в окне,
установка/удаление, автозапуск трея. Не проверено вживую: определение настоящего
VPN-адаптера (в тестовой машине VPN не было) и сетевой блок `block_nets`.

## Удаление (macOS)

```bash
sudo vpn-guard uninstall
sudo rm -rf "/Applications/Vafa.app" /usr/local/bin/vpn-guard /usr/local/etc/vpn-guard.conf /usr/local/etc/vpn-guard.apps
```
